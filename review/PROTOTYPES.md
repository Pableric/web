# SofL first-screen review

The three directions use the same commercial message and qualified figures.
They are intentionally different compositions, not theme variations.

## Runnable directions

- [A — Quant Infrastructure](../prototypes/quant-infrastructure/index.html)
- [B — Scientific Editorial](../prototypes/scientific-editorial/index.html)
- [C — Precision Luxury](../prototypes/precision-luxury/index.html)

Open [the review index](../prototypes/index.html) through a local HTTP server to
compare all three. From the repository root:

```sh
python3 -m http.server 4173
```

Then visit `http://127.0.0.1:4173/prototypes/`.

## Static captures

Each direction has:

- a 1440 × 1100 desktop fold;
- a 390 × 844 mobile fold;
- a long desktop composition showing the metric band and next scene;
- a long mobile composition showing the same narrative.

The captures are in [`review/screenshots/prototypes/`](./screenshots/prototypes/).

## Recommendation

Direction B, Scientific Editorial, is the strongest base for the complete
site. Its typography and asymmetry have the intended studio-quality presence,
while Direction A's precise metric grid and technical labeling can be carried
into the validation and product sections.

This is a review build only. All numerical claims remain blocked from public
deployment until the final claims ledger is approved.
